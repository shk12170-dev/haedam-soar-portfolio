## 배운 점
- `.env`·인증서처럼 git에 안 올라가는 파일은 폴더를 지우기 전에 저장소 밖(`vms/keys` 등)에 복사해 두고, 복사본이 실제로 있는지 확인한 뒤 지운다.
- Git Bash에서 `docker exec ... /var/...` 처럼 슬래시로 시작하는 경로는 `MSYS_NO_PATHCONV=1`이 필요하다.
