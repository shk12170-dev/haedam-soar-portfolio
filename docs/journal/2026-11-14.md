## 배운 점
- `.env`·인증서처럼 git에 안 올라가는 파일은 폴더를 지우기 전에 저장소 밖(`vms/keys` 등)에 복사해 두고, 복사본이 실제로 있는지 확인한 뒤 지운다.
- Git Bash에서 `docker exec ... /var/...` 처럼 슬래시로 시작하는 경로는 `MSYS_NO_PATHCONV=1`이 필요하다.
- 공격 입력은 Kali(WAN, 203.0.113.0/24)에서 pfSense WAN NAT을 거쳐야 하며, 포털의 팀 VPN 주소(10.250.0.2)로 직접 쏘면 안 된다(Kali는 VPN에 없음).
- 케이스 메인 워크플로가 부르는 하위 워크플로(`haedam-10/11/12/13/14/15`)는 팀 기본값대로 비활성이라, 탐지만 보려 해도(관찰 모드라도) 해당 회차에 필요한 하위 워크플로를 먼저 활성화해야 한다.
- Graylog 이벤트 정의의 알림 grace_period는 (최소 이 설정에서는) **정의 전체 단위**로 걸린다. 같은 정의의 여러 그룹(다른 username+src_ip)을 연이어 실측하려면 grace_period_ms(1800000 = 30분) 간격을 두거나, 회차 사이 대기 시간을 계획에 반영해야 한다.
