## 환경 준비

- **증상:** PowerShell에서 `git clone` → `'git' 용어가 cmdlet … 으로 인식되지 않습니다`.
  **원인:** Git이 PATH에 없었음. **조치:** Git 2.56 설치 후 새 터미널에서 인식.
- winget으로 Python 3.12.10, GitHub CLI 2.103.3, OpenVPN 2.7.701, Docker Desktop 4.99.0 설치.
- **막힘:** `systeminfo` → `Virtualization Enabled In Firmware: No`. BIOS의 AMD SVM이 꺼져 있어 VMware 64비트 VM과 Docker Desktop(WSL2)을 쓸 수 없음. BIOS 설정 후 재부팅 필요.
- **막힘:** VMware Workstation Pro는 winget에 없음(Broadcom 포털 로그인 후 다운로드).
- **주의:** `python` 명령은 WindowsApps 스텁으로 연결돼 동작하지 않음. 설치본 경로(`%LOCALAPPDATA%\Programs\Python\Python312\python.exe`)로 `.venv`를 만들어 사용.

- **해결:** 첫 재부팅은 Windows 재시작만이라 가상화가 그대로 꺼져 있었음. ASUS PRIME A520M-K BIOS(`Del` → `F7` Advanced → CPU Configuration → **SVM Mode = Enabled** → `F10`)에서 켠 뒤 하이퍼바이저 감지 확인.
- WSL을 3.0.5.0(커널 6.18)으로 업데이트(`wsl --update --web-download`), `%USERPROFILE%\.wslconfig` 작성: `memory=9GB`, `processors=8`, `swap=4GB`, `kernelCommandLine = sysctl.vm.max_map_count=262144`.
- Docker Desktop 엔진 29.9.3, Compose v5.7.0 기동 확인: `hello-world` 성공, `docker info` CPU 8·메모리 약 8.7GiB, 컨테이너 안 `vm.max_map_count = 262144`.
