### 기동 순서와 주의점

1. pfSense VM → 시계 확인
2. OpenVPN 서비스 → `10.250.0.1` ping 확인. **pfSense보다 먼저 떠 있었으면 클라이언트가 300초 재시도 대기에 들어가므로 서비스를 재시작한다**(2026-11-16 확인).
3. Docker 컨테이너: `soc-mongo`·`soc-opensearch` → `soc-graylog`(healthy 확인), `ticket-store`, `n8n`, Wazuh
4. DB VM → 포털 VM → `http://10.250.0.2:5000/api/v1/health` 200
5. Kali는 메모리를 확보한 뒤 마지막에 켠다

### 메모리 예산 (2026-11-16 실측)

Docker(vmmem) 약 6.3GB + VM 3대 약 3.0GB → 여유 0.3~0.7GB. **Kali(1GB)를 켜기 전에 브라우저·Discord 등을 닫는다.** 시험 중 메모리 부족으로 컨테이너가 재시작되면 그 회차는 무효로 기록한다.
